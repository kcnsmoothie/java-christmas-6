## 구현 기능 목록

### 입력

- 식당 예상 방문 날짜
- 주문하실 메뉴를 메뉴와 개수

---

### 출력

- <주문 메뉴>
    - 메뉴명 %d개
- <할인 전 총주문 금액>
- <증정 메뉴>
- <혜택 내역>
- <총혜택 금액>
- <할인 후 예상 결제 금액>
- <12월 이벤트 배지>

---

- 총 주문 금액 10000원 이상부터 이벤트 적용
- 음료만 주문 시, 주문 불가
- 메뉴는 한 번에 최대 20개까지

### 할인 이벤트

- 크리스마스 디데이 할인
    - 이벤트 기간: 2023.12.1 ~ 2023.12.**25**
    - 12월 1일부터 총 주문 금액에서 1000원 할인 시작
    - 크리스마스에 가까워질수록 할인금액 +100 ( 12/2 : 1100, 12/25 : 3400 )
- 평일 할인
    - 일요일 ~ 목요일
    - 디저트 메뉴 1개당 2023원 할인
- 주말 할인
    - 금요일, 토요일
    - 메인 메뉴 1개당 2023원 할인
- 특별할인
    - 이벤트 달력에 별이 있는 날

      ![image.png](attachment:b8ff77c0-6efb-4972-8438-9d5910ddd6a9:image.png)

    - 총주문 금액에서 1,000원 할인
- 증정 이벤트
    - 할인 전 총 주문 금액 ≥ 12만원
    - 샴페인 1개 증정

### 이벤트 배지

- 총 **혜택** 금액
    - 5천 원 이상: 별
    - 1만 원 이상: 트리
    - 2만 원 이상: 산타

## 기능 구현 사항

- 입력
    - [x]  날짜 입력
    - [x]  주문 메뉴와 개수 입력
        - 구분자 단위로 파싱
        - Map<Menu,Integer>로 메뉴와 개수 관리
- 기능
    - 이벤트 판별
    - 할인 전 총 주문 금액 계산 기능
    - 증정 메뉴가 있는지
    - 혜택 내역
        - [ ]  날짜가 25보다 작거나 같은지
        - [ ]  날짜가 주말인지 평일인지
           - 평일 : 날짜 % 7 == 3,4,5,6,0
           - 주말 : 날짜 % 7 == 1,2
        - [ ]  날짜가 특별할인에 해당하는 날 인지
        - [ ]  할인 전 총 주문 금액 ≥ 12만원
        - 예시

            ```java
            크리스마스 디데이 할인: -1,200원
            평일 할인: -4,046원
            특별 할인: -1,000원
            증정 이벤트: -25,000원
            ```

    - 총 혜택 금액
        - 혜택 내역 합 계산
    - 할인 후 결제 금액
        - 할인 전 총 주문 - 총 혜택 금액
    - 12월 이벤트 배지

## 예외 처리

- 에러 문구는 반드시 `[ERROR]` 로 시작해야 한다.
- 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException` 발생
- `[ERROR]` 메시지 출력 후 **해당 입력부터 다시 받는다**

### 유연하게 허용할 예외

- 공백 포함한 정상 입력 (예: `" 1 , 2 , 3 , 4 , 5 , 6 "` → 정상 처리)

### 식당 예상 방문 날짜

- 1 이상 31 이하의 숫자가 아닐때

    ```java
    [ERROR] 유효하지 않은 날짜입니다. 다시 입력해 주세요.
    ```


### 주문 메뉴와 개수

- 메뉴판에 없는 메뉴를 입력

    ```java
    [ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요.
    ```

- 메뉴의 개수 1 이상의 숫자가 아닐 때

    ```java
    [ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요.
    ```

- 메뉴 형식이 예시와 다를 때

    ```java
    [ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요.
    ```

- 중복 메뉴를 입력했을 때

    ```java
    [ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요.
    ```
